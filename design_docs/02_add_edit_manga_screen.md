# Add/Edit Manga Screen

**Screenshot:** `Screenshot_20250925-213436_Brave.jpg`

This screen allows users to add a new manga to their collection or edit an existing one.

## Components

*   **App Bar:**
    *   Title: "manabee"
    *   Actions:
        *   Settings icon on the right.
*   **Cover Image:**
    *   A large placeholder for the manga's cover image.
    *   A "+" icon indicates that the user can add an image.
*   **Chapter List:**
    *   A list of folders, each representing a chapter.
    *   Each item displays the file path to the chapter's folder.
*   **Action Buttons:**
    *   "add new page/folder" button to add more chapters.
*   **Bottom Navigation Bar:**
    *   Three icons:
        *   Home
        *   A message/chat icon.
        *   A folder/collection icon.
