# Dictionary/Tags Screen

**Screenshot:** `Screenshot_20250925-213510_Brave.jpg`

This screen serves as a personal dictionary for the user, listing all the words they have saved from their reading.

## Components

*   **App Bar:**
    *   Title: "manabee"
    *   Actions:
        *   Settings icon on the right.
*   **Book-Specific Words:**
    *   A section for words from a specific book (e.g., "Blue Period").
    *   A list of saved words, each displayed as a card with:
        *   English
        *   Romaji
        *   Furigana
        *   Kanji
*   **Global Dictionary Search:**
    *   A section titled "Dictionary".
    *   A search bar to look up any word.
    *   The search result is displayed in a card format similar to the book-specific words.
*   **Bottom Navigation Bar:**
    *   Three icons:
        *   Home
        *   A message/chat icon (selected).
        *   A folder/collection icon.
