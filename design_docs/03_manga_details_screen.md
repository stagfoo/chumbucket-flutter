# Manga Details Screen

**Screenshot:** `Screenshot_20250925-213422_Brave.jpg`

This screen provides details about a selected manga and allows the user to choose a chapter to read.

## Components

*   **App Bar:**
    *   Title: "manabee"
    *   Actions:
        *   Settings icon on the right.
*   **Manga Information:**
    *   Large cover image on the left.
    *   To the right of the cover:
        *   Manga title ("Mushishi").
        *   "Last Page Read" with a small preview of the page.
        *   "Page 10 of 100 Read" progress indicator.
*   **Chapter List:**
    *   A section titled "All Chapters".
    *   A list of chapters, each with:
        *   Chapter number and title (e.g., "01# Chapter").
        *   A message/comment icon with a number.
*   **Bottom Navigation Bar:**
    *   Three icons:
        *   Home
        *   A message/chat icon.
        *   A folder/collection icon.
