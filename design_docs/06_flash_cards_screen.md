# Flash Cards Screen

**Screenshots:**
* `Screenshot_20250925-213520_Brave.jpg` (Card Front)
* `Screenshot_20250925-213539_Brave.jpg` (Card Back)

This screen helps users review the words they've saved using a flashcard system.

## Components

*   **App Bar:**
    *   Title: "manabee"
    *   A hamburger menu icon on the left.
*   **Progress Indicator:**
    *   "FLASH CARDS" title.
    *   A score indicating progress (e.g., "20 👍 / 30 👎").
*   **Flash Card:**
    *   **Front:**
        *   Displays a word in Japanese (e.g., "若い").
        *   Shows the furigana and romaji (e.g., "わかい", "wakai").
        *   A "flip" icon in the top right corner.
    *   **Back:**
        *   Shows the detailed dictionary entry for the word, similar to the dictionary lookup card in the reader view.
        *   Includes definitions, tags, and links.
*   **Card Navigation:**
    *   "3/50" counter indicating the current card number.
    *   Back and forward arrows to move between cards.
*   **Review Actions:**
    *   Thumbs up and thumbs down buttons, presumably to mark the card as known or unknown.
*   **Bottom Navigation Bar:**
    *   Three icons:
        *   Home
        *   A message/chat icon.
        *   A folder/collection icon (selected).
