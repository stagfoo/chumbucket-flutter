This is the core screen for reading manga and interacting with the text.

## Components

*   **App Bar:**
    *   Title: "manabee"
    *   A hamburger menu icon on the left.
*   **Manga Page View:**
    *   Displays the current manga page.
    *   Users can pan and zoom.
*   **Text Bubbles:**
    *   Overlays on top of the manga page.
    *   These bubbles contain the translated text.
    *   They can be moved and edited.
*   **Floating Action Button:**
    *   A yellow "+" button, likely for adding a new text bubble.
*   **Dictionary Lookup:**
    *   When a word is tapped or selected, a dictionary card slides up from the bottom.
    *   The card shows:
        *   The word in Japanese (e.g., "wakai").
        *   Furigana reading (e.g., "わか").
        *   The word in Kanji (e.g., "若い").
        *   Tags like "common word", "jlpt n5", "wanikani level 16".
        *   Links for "Play Audio", "Show inflections", and "Links".
        *   Definitions of the word (e.g., "1. young; youthful").
*   **Bottom Bar (in reader mode):**
    *   A simplified bar, possibly showing page number or other reading-specific controls. It seems to be collapsed or hidden in the screenshots.
